THE NEX CODEX FIELD GUIDE

Make yourself at home.

A few simple steps to a more connected community.

01 / Connect your server

The bot owner creates a Discord application, enables the Server Members and Message Content privileged intents, and invites the bot with the bot and applications.commands scopes. See the project README for installation commands and permission details.

Sign in with Discord, choose a server, and open its workspace. Staff handle tickets, announcements, giveaways and authorized payment review. Bot owners and server administrators configure settings. Only bot owners listed in OWNER_IDS add products and create shop panels. The supplied cyan artwork loads automatically when the bot starts; no emoji setup command is required. Keep the bundled image folder when hosting.

02 / Set up the essentials

Set staff roles, ticket category, and logging channel first. Configure welcome and leave messages. Use /welcome and /leave to set channels, templates and previews.

Use /say for plain announcements and /broadcast for a branded embed. Both require staff access and suppress mentions.

03 / Build your storefront

Create server templates or bot source code with /addproduct or in the dashboard Products page. Discord price fields use currency units: 499.00. Dashboard forms use minor units: 49900 means 499.00. Add delivery instructions, a secure HTTPS link, or a file placed by the owner in the private product directory. Publish when ready, then use owner-only /createshop to post a persistent browse button.

04 / Configure manual payments

Enter your actual UPI ID, payee name, QR image URL, currency, and reviewer roles. The customer confirms an order with /buy and receives a private ticket. They upload a screenshot with /payment. Staff check the actual transaction independently and explicitly approve or reject it.

NEX CODEX does not connect to a payment gateway, automatically verify screenshots, or send refunds. Verified customers retrieve products using /deliver or My orders.

05 / Keep your community growing

Use /help for the actual command menu. Create giveaways, welcome members, publish announcements, open private tickets and browse products.

Privacy & permissions

Dashboard sign-in requests your Discord identity and server list. It never asks for your Discord password. Server access is verified using Discord membership and roles. Sessions expire after eight hours.

The bot stores Discord IDs, configuration, orders, receipts as attachment URLs, moderation reasons, and audit records. Keep audit/log channels private. Historical moderation records may remain from earlier versions; this focused release does not run message edit/delete logging. Ticket transcripts are exported to staff DMs on request. See README for retention and deletion guidance.

Server administrators can access private channels under Discord's permission model. Download links can be copied by recipients; use private file delivery when access must be checked on every download.
