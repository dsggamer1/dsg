THE NEX CODEX FIELD GUIDE

Make yourself at home.

A few simple steps to a more connected community.

01 / Connect your server

The bot owner creates a Discord application, enables the Server Members and Message Content privileged intents, and invites the bot with the bot and applications.commands scopes. See the project README for installation commands and permission details.

Sign in with Discord, choose a server, and open its workspace. Staff see tools their server roles permit; administrators configure settings.

02 / Set up the essentials

Set staff roles, ticket category, and logging channel first. Configure welcome and leave messages. Enable leveling, then set XP cooldowns and safe reward roles.

Automod and security alerts start disabled. Tune exemptions and thresholds for your community before enabling them. Automod defaults to logging signals for review.

03 / Build your storefront

Create templates, bot source code, or hosting plans in Products. Enter prices in minor currency units: 100 means 1.00. Add delivery instructions, a secure HTTPS link, or a file placed by the owner in the private product directory. Publish when ready.

04 / Configure manual payments

Enter your actual UPI ID, payee name, QR image URL, currency, and reviewer roles. The customer confirms an order with /buy and receives a private ticket. They upload a screenshot with /payment. Staff check the actual transaction independently and explicitly approve or reject it.

NEX CODEX does not connect to a payment gateway, automatically verify screenshots, or send refunds. Verified customers retrieve products using /deliver or My orders.

05 / Keep your community growing

Use /help for the actual command menu. Create giveaways, set reminders, moderate your server, and manage roles. Hosting orders go to a manual queue; staff provision the service before recording it as running.

Privacy & permissions

Dashboard sign-in requests your Discord identity and server list. It never asks for your Discord password. Server access is verified using Discord membership and roles. Sessions expire after eight hours.

The bot stores Discord IDs, configuration, orders, receipts as attachment URLs, moderation reasons, and audit records. Message edit/delete logs can contain message content; only enable logging in an appropriately private channel. Ticket transcripts are exported to staff DMs on request. See README for retention and deletion guidance.

Server administrators can access private channels under Discord's permission model. Download links can be copied by recipients; use private file delivery when access must be checked on every download.
